命令 → harness 操作映射

/帮助 /help静态帮助文本，router 直接返回
/状态 /status读 settings（工作区/模型）+ 当前会话轮数 + 是否有任务在跑
/新建 /newdrivers.startSession() 创建新会话并重新绑定，同 /bind 的会话替换
/会话 /sessions列出绑定历史中最近 N 个会话（标题 + 相对时间）
/切换 N /switch切换绑定到第 N 个历史会话
/项目 /project无参=显示当前工作区；带参=切换（需 harness 支持多工作区）
/模型 /model无参=列出 agent-default-model 可选模型；带参=写 settings 切换
/模式 /mode切换 plan/normal 运行模式（写会话 agentOptions）
/回复 /reply轮换 简洁/标准/详细 回复详细程度（影响最终回复的摘要策略）
/轨迹 /trace任务 #8：读取最近轮次的 tool/call、tool/result 事件拼装
/取消 /cancel中断 inflight 轮次（agent.followup 的取消句柄）
/bind /unbind已有（口令绑定 / 解绑）
